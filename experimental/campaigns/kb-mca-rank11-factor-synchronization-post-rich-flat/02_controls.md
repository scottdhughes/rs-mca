# Controls

## Positive controls

1. **Disjoint starting packets.** Residual slopes inherit the predecessor's
   anchor-relative row-space partition.  Loads are summed only across these
   disjoint packets.
2. **Immediate parents.** A heavy proper flat may yield a parent of dimension
   larger than `dim U+1`; a deterministic intermediate space of exactly one
   greater dimension is chosen inside its orthogonal complement.
3. **Merged parents.** Coincident immediate parents are merged before applying
   the pair-list cap.
4. **Parent cap.** Every assigned pair difference has both coefficient rows in
   the parent `W`, so all assigned pairs lie in
   `(a_0+W) x (b_0+W)`.
5. **Actual coordinates.** Every common-zero set lies inside the fixed actual
   anchor-good support.  The ambient set-system universe is bounded by `m`,
   not by the possibly larger complete pair core.
6. **Canonical subsets.** If a parent has more than `42,448` common zeros, one
   canonical subset of exactly that size is used in the moment identities.

## Hostile controls

1. The same row-space group may not be routed to several parents.
2. The same parent may not be charged once for every incoming child.
3. A parent count cannot be inferred from pair types; it uses the
   dimension-three cap on assigned **slopes**.
4. Pairwise/triple intersections are not assumed uniformly.  Only existence of
   the certified subfamilies is claimed.
5. The synchronized sum-space need not itself be represented by one minimizing
   pair and is not declared paid.
6. Common-locator cancellation is not yet promoted to an active-v4 owner.

## Finite controls

The primary verifier exhausts small uniform set systems and checks the balanced
degree-sequence intersection bound.  It also exhausts small weighted systems
and checks the weighted coordinate-subset load identity.  The independent
audit uses separate combination recurrences and no imports from the primary
verifier.
