# 1. Source-bound global-core descent

Put `R=1,048,576`, `d=67,472`, and
`L_start=B*-134,944+1=274,980,728,111,260,144`.

For a nominal explanation-direction rank `s`, the imported pointwise resource
is

\[
 C_s(K)=\left\lfloor\max\left\{
 \frac{(R+K)^{\underline{s+1}}}{(d+K)(d+1)^{\overline{s-1}}},
 \frac{(R+s)^{\underline{s+1}}}{(d+1)^{\overline s}}
 \right\}\right\rfloor .
\]

Complete minimizing-pair cores give a coordinate incident to at least

\[
 I_s(K,L)=\left\lceil\frac{L(d+K)-C_s(K)}{R+K}\right\rceil
\]

selected pairs.  The parent theorem says that this coordinate either gives a
proper rank drop after source-bound locator shortening, or belongs to every
selected pair core and shortens the whole family without losing a slope.

At `K=s` the global alternative is impossible because the full degree-`<s`
code contains `1`.  Exact scans over every `s<=K<=1,048,576` show that the
global minimum is attained at `K=s`.  Hence

\[
 L_{s-1}=\left\lceil\frac{L_s(d+s)-C_s(s)}{R+s}\right\rceil .
\]

For error rank 12 (`s=11`) this yields `L_3=80,415,635`.
For error rank 13 (`s=12`) it yields `L_4=73,640,859`.

If an actual span is smaller, pad it to the nominal rank.  This only weakens
the resource; equality of the incident span with the padded space is still
generated by actual pair differences, so the global-core conclusion remains
valid.
