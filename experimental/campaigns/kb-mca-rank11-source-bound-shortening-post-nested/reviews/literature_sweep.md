shortening/puncturing definitions, re-encoding by forced zero coordinates, and
recent RS--MCA shortening work.

coordinates gives an `[n-k,K-k]` GRS code is consistent with the locator
calculation used here.  No external theorem is load-bearing: the support-wise
pair-noncontainment lift is proved directly because that semantic clause is
specific to this MCA setting.
